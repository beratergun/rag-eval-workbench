# Security Policy

RAG Eval Workbench is a local evaluation prototype. It does not require network access, credentials, a live LLM, or a vector database.

Use synthetic or approved recorded datasets only. Do not place secrets, personal data, private production transcripts, or confidential retrieval content in issues or example files.

Please report a suspected vulnerability privately through GitHub's security-reporting channel when available. Include a minimal synthetic reproduction and avoid attaching sensitive data.
